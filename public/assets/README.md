# Where every file goes

Drop files in with **exactly these names**. Anything missing just shows its labelled placeholder,
so you can add photos one at a time and nothing breaks.

JPG photos around 1600–2000 px on the long side are plenty (keep each under ~500 KB if you can).

## Photos — `public/assets/photos/`

| File | Where it appears |
|---|---|
| `01-childhood/siblings-with-grandmother.jpg` | Ch 1 — the four siblings with their mother (the key photo; it "develops" from sepia) |
| `04-love-story/wedding.jpg` | Ch 4 — the wedding photo inside the gold arch (portrait / tall works best) |
| `04-love-story/mumma-dad-1.jpg` … `mumma-dad-4.jpg` | Ch 4 — the sliding strip of Mumma & Dad (square-ish) |
| `05-fayola/fayola-mumma-1.jpg` … `fayola-mumma-3.jpg` | Ch 5 — Fayola & Mumma |
| `06-shaun/shaun-mumma-1.jpg` … `shaun-mumma-3.jpg` | Ch 6 — Shaun & Mumma |
| `06-shaun/height-1.jpg` … `height-4.jpg` | Ch 6 — the height sequence, oldest (1) to tallest (4). Tall/portrait photos |
| `08-family/family-01.jpg`, `family-02.jpg`, … | Ch 8 — tiles of the big heart. Add as many as you like, then set `familyPhotoCount` in `config/site.js` |
| `09-letter/family-1.jpg` … `family-3.jpg` | Ch 9 — photos beside the letter |
| `09-letter/mumma-portrait.jpg` | Ch 9 — cut into the tiles that drift together into her portrait (portrait, roughly 4:5) |
| `final/mumma.jpg` | Final screen — the oval portrait (portrait, roughly 4:5) |

Chapters 2 and 3 are illustrations, so they need no photos.

## Video — `public/assets/video/`

- `family-wishes.mp4` — the family compilation (H.264 MP4 plays everywhere).
- `family-wishes-poster.jpg` — optional still shown before it plays.

## Music — `public/assets/audio/`

- `soundtrack.mp3` — loops in the background. Without it, a soft generated piano plays.
